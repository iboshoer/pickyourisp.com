Internet technologies

Learn the basics of common home internet connection types. Technology names describe how a connection works, not what is available at a particular address.

Fiber internet

Technology explainer

PLACEHOLDER

Fiber internet sends data through fiber-optic cable, using light to move information between a home and the network.

Learn about fiber internet

Cable internet

Technology explainer

PLACEHOLDER

Cable internet typically uses a hybrid network that combines fiber in the wider network with coaxial cable for the final connection.

Learn about cable internet

DSL internet

Technology explainer

PLACEHOLDER

DSL uses a telephone-line connection for internet access. The capabilities of a DSL connection can depend on the line and the network serving it.

Learn about dsl internet

Satellite internet

Technology explainer

PLACEHOLDER

Satellite internet connects a home to a provider network through a satellite link, using equipment installed at the location.

Learn about satellite internet

Fixed wireless internet

Technology explainer

PLACEHOLDER

Fixed wireless uses a radio link between equipment at a fixed home or business location and a provider network site.

Learn about fixed wireless internet

5G home internet

Technology explainer

PLACEHOLDER

5G home internet uses a cellular network and a fixed receiver or router to connect a home to the internet.

Learn about 5g home internet
